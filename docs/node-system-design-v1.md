## 1. 调研结论摘要

### 1.1 参考产品：Google Flow 节点卡片
- 节点 = 白色圆角卡片，**选中时**：头部（类型色点+标题+右侧状态字）、内容区、底部"生成区"（+ 按钮、预设 chip、提示词输入、模型/参数/高级 药丸下拉、橙色发送圆钮）、左右边缘中部两个**橙色圆形手柄**、卡片上方**药丸悬浮工具栏**。未选中/失焦 = **自动收缩**：仅显示标题小字（悬在卡片左上）+ 紧凑卡片，无工具栏、无页面手、无 footer。
- 文本节点收缩态保留灰色编辑区（文本摘要+占位符）；图片节点收缩态 = 虚线框空位/缩略图；视频节点收缩态 = 媒体缩略图 + 播放按钮。

### 1.2 开源无限画布共性
- 摄像机 = `{x, y, zoom}` 三元组，整层单个 CSS transform；`screenToFlow` / `flowToScreen` 双向换算。
- 背景点阵网格单独一层、随相机绘制；连线走 SVG 层；节点内容用 DOM（Vue 组件）——混合渲染是业界主流（tldraw / React Flow / ComfyUI 同款取舍）。
- 缩放手势：滚轮 = 平移或缩放（视产品而定，**Flow 系用 ctrl/⌘+滚轮 & 触控板捏合缩放**）、空格 + 拖拽平移、中键拖拽平移；缩放范围 0.1x–4x。
- 选中态：描边 + 手柄；文本类节点**固定宽度、高度随内容**（tldraw note growY / 缩字下限）；媒体节点**锁定宽高比 + 最小尺寸**（tldraw embed 200px、Excalidraw lockAspectRatio、React Flow NodeResizer keepAspectRatio）。
- 收缩/折叠的通用交互：**点击外部自动收缩、点击/双击展开、工具栏按钮显式切换**（ComfyUI 折叠、Figma 折叠 Section 同源）。
- 撤销重做：事务化快照，仅在拖拽结束、删除、连线等"离散动作"提交（避免拖动每帧污染历史）。
- 快捷键：Space/中键平移、Ctrl+滚轮缩放、Ctrl+0/F 适配、Ctrl+Z/Ctrl+Shift+Z 撤销重做、Delete 删除、Ctrl+D 复制。

## 1.3 竞品：LibTV（哩布哩布AI，liblib.tv，2026-03 上线）
- **与我们的定位几乎完全一致**：无限画布 + 节点工作流；5 种基础节点（文本/图片/视频/音频/脚本），双击画布空白新建节点，拖文件入画布自动建节点。
- **连线语义（关键）**：节点间拖拽连线自由连接，"上游输出=下游输入"；**连线顺序决定上游引用顺序**（`{{Image 1}}`、`{{Video 1}}` 引用第 N 个上游）；文本连入图片=提示词加强控制；图片连入视频=生成视频（首帧）；连接 ≥2 个视频节点后"一起往右拖线"可触发**视频合成**（时间轴编辑面板）。
- **端口模型**：CLI 参数 `--left X`（设入边）、`--right X`（设出边）、`--left-add/--left-rm`（增删连线）→ 节点 = 左侧输入 + 右侧输出 两侧端口，每条边独立。
- **工作流复用**：框选打组 Ctrl/Cmd+G → 右键"创建工作流"存为模板复用；工作流含连线关系可导出 JSON；跨画布复制粘贴**带连线**。
- **周边**：节点内 `/` 调出 20+ 专业功能（多机位九宫格、25 宫格连贯分镜、角色三视图…）；主体库节点绑定角色保持跨镜头一致性；每个节点可独立换模型/重新生成；Agent 可经 Skill 调用画布（人/AI 双用户）；团队版支持多人实时协作。
- 来源：量子位 qbitai.com/2026/03/390320.html、百度百科 LibTV、CSDN《LibTV 全攻略》。

## 2. 目标交互模型（对齐参考截图）

| 状态 | 触发器 | 呈现 |
|---|---|---|
| 展开 | 点击/选中节点 | 完整卡片 + 悬浮工具栏 + 左右端口 |
| 自动收缩 | 点击空白/失焦 | 标题小字 + 紧凑卡片（无工具栏/端口/footer） |
| 编辑中 | 双击文本内容区 | 文本节点进入编辑（仅文本节点；图片/视频展开即编辑） |

- 拖拽节点/工具栏按钮全部 `nodrag`；文本可编辑元素 `nodrag nowheel`。
- 端口 = 连线 handle：左 = 输入（target），右 = 输出（source），拖线生成贝塞尔边（沿用当前 Vue Flow 连线）。
- 宽度调整：**左右橙色圆手柄 = 拖动改宽度**（Flow 卡片同款）；文本节点高度随内容自适应，图片/视频按宽高比锁定。

## 3. 数据结构变更（canvas store）

```
node.data = {
  expanded: boolean,   // 展开/收缩
  width?: number,      // 自定义宽度（null = 默认）
  content: string,     // 文本内容
  prompt: string,      // 生成区提示词
  model / size / ratio / duration / resolution / count: ...  // 保留现有字段
  url / base64 / fileName: ...                                // 媒体字段（保留）
}
```

## 3.1 多连线语义（对齐 LibTV 与生成流惯例，见原型"连线示例"区块）

| 连线 | 语义 | 数量 |
|---|---|---|
| 文本 → 图片 | 提示词（可多条，按连接顺序编号 {{Prompt 1}}、{{Prompt 2}}…） | 多进一 |
| 文本 → 视频 | 运动/动作描述 | 多进一 |
| 文本 → 文本 | 引用/LLM 改写源 | 一进一 |
| 图片 → 图片 | 参考图/重绘编辑源 | 多进一 |
| 图片 → 视频 | 首帧（视频节点左侧可再加"尾帧"输入锚，或边 data.role = first/last） | 各一 |
| 视频 → 文本 | 描述/总结（LLM 分析上游视频） | 一进一 |
| 视频 + 视频 → ？ | 预留：≥2 视频汇聚 = 视频合成（时间轴），参考 LibTV | — |

**端口模型（贯穿所有节点）**：左侧 = 输入锚（单锚点，可汇聚多条边，边按连接顺序编号"引用"）；右侧 = 输出锚（单锚点，可扇出多条边）。拖动橙柄 → 改宽度（+高度自适应）；从橙柄拖出 → 连线（十字光标）；连线删除/重连沿用 Vue Flow 边机制。
