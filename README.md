# Ling Canvas

Ling Canvas 是一个基于 Vue Flow 的可视化 AI 创作画布，支持文本、图片与视频节点编排，以及自定义 OpenAI 兼容 API 模型。

![Vue](https://img.shields.io/badge/Vue-3.5-4FC08D?logo=vue.js)
![Vite](https://img.shields.io/badge/Vite-5.2-646CFF?logo=vite)

## 功能

- 无限画布与节点连线
- 文本、图片、视频创作节点
- 项目管理与回收站
- 模型供应商与模型选择管理
- 深色、浅色主题
- 本地项目与配置保存

## 开发

```bash
pnpm install
pnpm dev
```

或使用 npm：

```bash
npm install
npm run dev
```

## 构建

```bash
pnpm build
```

## API 配置

在应用内的模型配置页添加你自己的 API 供应商、接口地址和密钥。项目不内置任何第三方 API 密钥或服务地址。
